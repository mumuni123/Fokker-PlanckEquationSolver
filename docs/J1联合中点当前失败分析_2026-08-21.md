## 2. 总结结论

J1 当前有两个不同层次的真实问题：

1. **unit 已完成非线性收敛，但联合 x/u/Poisson flux 不满足能量闭合。**
2. **smoke 的 Newton line search 允许大幅负质量 candidate 参与并被接受，故它沿非物理解缓慢下降后以 code 74 结束。**

因此当前不是 Poisson、Gauss、MPI 崩溃、diagnostic writer 或单纯迭代次数问题。J2 继续禁止进入。

## 3. J1 unit：真实 energy closure 失败

`joint_midpoint_j1_unit.result`：

```text
accepted=0
finite=1
gauss_ok=1
converged=1
iterations=2
residual_linf=2.2557191959832622e-11
poisson_residual_linf=3.6217416010677362e-16
energy_residual=1.1132815186046597e14
failure_code=75
```

解释：

- 相空间 residual 已低于 $10^{-10}$；
- 相对 Gauss residual 已低于 $10^{-8}$；
- 没有 NaN/Inf；
- 失败发生在收敛之后的 `joint_midpoint_energy_residual` 门。

所以 code 75 是**真实的联合离散能量恒等式失败**，不是 Newton 未收敛或 Poisson 未解好。

当前能量门检验：

$$
R_E=
\Delta K_u+\Delta U_E-W_{\rm electrode}.
$$

在 background-only、无 Beam/Tail/collision 的制造态中，$R_E$ 应为稳定求和误差；当前为
$1.11\times10^{14}\ \mathrm{J/m^2}$，不能通过容差放宽解释。

### 3.1 已排除项

- `gauss_ok=1`、relative Gauss residual $3.62\times10^{-16}$：不是 Poisson 收敛问题；
- `converged=1`：不是非线性 residual 停在错误解之外；
- J0 已验证 mass、u kinetic telescoping、cell volume、$G/G^*$ 基础恒等式：不是简单单位或端点权重问题；
- 无 Beam/Tail/collision：不是开放粒子源、PIC current 或碰撞 ledger 问题。

### 3.2 目前能确定的根因

当前 `evaluate_local_residual()` 用两个分别定义的中心 trace：

$$
F_x=v^H\frac{M_L+M_R}{2},
\qquad
F_u=a\frac{M_j/\Delta u_j+M_{j+1}/\Delta u_{j+1}}{2}dx\,A_\perp.
$$

虽然它们共享中点状态，仍没有构成同一个离散 Hamiltonian bracket。当前代码没有证明并实际不满足：

$$
\Delta K_u
=\Delta t\sum_i dx\,E_i(GJ_x)_i.
$$

这与此前 Strang 系统的结构性根因一致：**仅把两个独立 sweep 改成中心 trace，不会自动得到能量兼容的联合相空间算子。**

## 4. J1 smoke：非物理 candidate 与 code 74


这次没有 SIGSEGV；`vpfp_failure.dat` 和 `joint_midpoint_iteration.dat` 均已生成，说明 local slab

iteration 文件显示：

```text

iteration 20 residual = 3.7856e-08
relative Gauss residual ~= 6.3e-13
```

残差只下降约 6.6%，20 次后远未达到 $10^{-10}$。

更重要的是，line search 把下列 candidate 标为 accepted：

```text
iteration 3  min_mass = -1.21e-03
iteration 4  min_mass = -6.31e+02
iteration 7  min_mass = -2.31e+08
iteration 20 min_mass = -1.32e+08
```

这些不是舍入级负值。当前“signed trial”实现允许 line search 接受大幅负分布，只在最终收敛后检查 code 76；
因此 solver 正在沿非物理解寻找 residual 下降，code 74 并不代表正物理解不存在，也不能作为 J1 flux 的验收。

`vpfp_step_diagnostics.dat` 只有表头是正确行为：smoke 没有 accepted step，不能写入 accepted-state 物理诊断。

## 5. 不应采用的伪修复

禁止：

- 增加 `max_iterations`；
- 放宽 $10^{-10}$ residual 或 energy gate；
- soft accept；
- 把 `min_mass` 截断为零、重新加入 FCT、局部缩放 $a_u$；
- 调整 Poisson、端点权重、field scale、Beam/Tail 或碰撞。

这些操作会掩盖 code 75 或让 smoke 接受非物理解，不能修复 J1。

## 6. 必须的下一步

### 6.1 先补 unit 的能量项分解

在 `joint_phase_space_midpoint_energy_test.cpp` 和 `VpfpStepResult` 中新增并写出：

```text
delta_K_from_x_flux
delta_K_from_u_flux
field_energy_change
electrode_work
poisson_potential_charge_work
charge_current_work
u_energy_current_work
combined_energy_residual
```

所有项使用同一个 accepted candidate、同一个 $E^{n+1/2}$ 和明确单位。先定位 code 75 缺口是：

```text
A. x Hamiltonian work 与 u Hamiltonian work 不相等；
B. charge current work 与 Poisson potential work 不相等；
C. kinetic/field组合符号或时间层不一致。
```

在分解完成前，禁止改 flux 公式。

### 6.2 将 line search 改为正域求解，而非 signed accepted trial

Jacobian finite-difference probe 可以暂时是 signed，以避免零尾部锁死；但 line-search **accepted candidate**
必须满足：

$$
M_{trial}\ge -\tau_{neg},
\qquad
\tau_{neg}=4096\epsilon\max(1,\|M^n\|_\infty).
$$

若零 tail cell 使标准 fraction-to-boundary 得到 $\lambda=0$，不得允许大幅负 trial；需要采用下列之一：

1. active-set Newton：冻结零/低于支持阈值的未知量，并在 support 边界施加一致的零-flux trace；
2. 对 J1 制造态使用显式、守恒记录的正 support floor，并证明其质量/能量低于 roundoff budget；
3. 使用正变量参数化（例如受限 log/entropy variable），但必须保持质量约束并重新推导 Jacobian。

在三者中必须选择并单独测试；禁止把负 trial 作为 accepted line-search state。

### 6.3 J1 继续门

仅当以下条件全部满足，才允许重跑 smoke：

```text
unit 的 energy 分解已定位 code-75 首个不闭合项；
line search 不接受显著负 mass；
iteration history 中 min_mass >= -tau_neg；
J1 unit 与 smoke 均有完整 iteration/failure 输出。
```

若 energy 分解表明中心 trace 本身不满足 A/B/C 中任一恒等式，则停止当前 J1 center-trace 路线，
回到联合 weak-form/离散 Poisson bracket 的重新推导；不得进入 J2/J3。
