# 15.4 阶段 3：MUSCL/FCT 接回测试

本测试只运行固定中点、无 Beam 的 opt-in `dual_u_coupling`。生产默认仍为
`legacy_coupling`，测试不修改 `J_N`、Yee Ampere、Beam 或周期面拓扑。

## 编译

```bash
cmake -S . -B build_dual_u_stage3 \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER=mpicxx \
  -DFP_BUILD_BACKGROUND_COUPLING_TESTS=ON

cmake --build build_dual_u_stage3 -j 16 --target \
  background_coupling_dual_u_muscl_fct_test
```

## 运行

```bash
mkdir -p output/dual_u_stage3/muscl_fct

srun -N 10 -n 80 --ntasks-per-node=8 --cpu-bind=cores \
  ./build_dual_u_stage3/background_coupling_dual_u_muscl_fct_test \
  --output-dir output/dual_u_stage3/muscl_fct \
  > output/dual_u_stage3/muscl_fct/run.out \
  2> output/dual_u_stage3/muscl_fct/run.err
```

正式结果为：

```text
output/dual_u_stage3/muscl_fct/summary.result
```

Limiter 分布审计额外写入同一目录：

```text
limiter_distribution.dat
limiter_beta_zero_cells.dat
```

`limiter_distribution.dat` 分别给出 `normal` 与 `controlled` 场景，并按
`core/periodic_seam` 和 `thermal_body/near_abs_u_eq_1/low_density_tail`
分层。每层同时报告点数覆盖率、质量加权覆盖率、绝对电流加权覆盖率和
能量加权覆盖率。周期接缝区为左右各 `0.1 um`，仅用于审计分类。

`limiter_beta_zero_cells.dat` 给出每个已记录 `beta=0` cell 的全局 x 索引、
速度坐标、`m_low`、最终实际 `limited_outflow` 与二者比值。为防止异常场景
产生过大的文件，最多记录每个 MPI rank 的 2048 行；完整数量和截断数量在
`summary.result` 的 `*_beta_zero_*` 字段中。

`limiter_rate_pass` 不再以原始点数覆盖率作为失败条件。它只检查正常场景的：

- thermal-body 中具有 `m_low>0` 的唯一 donor 覆盖率；
- 限流单元的质量、电流绝对值、能量加权覆盖率；
- 累计 donor 触发次数不小于最终候选态的唯一 donor 单元数。

原始点数覆盖率仍写为 `normal_limiter_point_coverage_diagnostic`。其中
`beta=0 && m_low=0` 仅代表空速度尾部发生了可记录的出流，不计入物理 donor
退化。`*_donor_beta_cumulative_trigger_count` 是所有固定算子子阶段的累计触发
次数，`*_donor_beta_unique_cell_count` 是最终候选态的唯一单元数；二者不要求
相等，`trigger_minus_unique` 仅用于避免混用统计口径。

## 验收项

`summary.result` 中以下项必须全部为 `1`：

```text
bundle_contract_pass
center_high_no_limiter_pass
muscl_fixed_branch_pass
low_order_base_pass
fct_shared_alpha_pass
final_flux_moment_pass
limiter_rate_pass
final_pair_pass
passes
```

同时审计：

- `dual_only_final_pair_growth`：若 high 层闭合而 final 层明显增大，问题定位为 FCT 后同源性；
- `normal_x/u_limiter_active_fraction`：正常候选态的分方向限流率；
- `donor_cell_degradation_fraction`：donor beta 二次退化率；
- `normal_donor_beta_*` 与 `controlled_donor_beta_*`：分别比较正常及
  受控场景的累计/唯一 donor 数量、尾部占比和 `beta=0` 的空/非空 donor 分类；
- `shared_alpha_linf`：同一 u 面上 `fu` 与 `cu` 使用的 alpha 一致性；
- `final_flux_to_jn/je_linf`：最终限流通量到最终电流矩的直接恒等。
