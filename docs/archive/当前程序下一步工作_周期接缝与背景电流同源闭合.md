# 当前程序下一步工作：背景电流同源闭合与 `dual_u_coupling` 原型

## 1. 文档状态与用途

本文档根据截至 2026-07-19 的生产代码、正式长跑、checkpoint 审计、制造态测试和周期接缝定向审计完整重写。

当前阶段已经不再是“继续寻找周期接缝错误”，而是：

> 保留已经验证正确的背景连续性电流、Yee Ampere、Beam 轨迹沉积和核心宏观响应，在独立功能开关下构造与 x 连续性电流离散对偶的 `u_parallel` 受力通量原型。

本文档用于直接指导后续代码修改和验收。除非新结果推翻本文中的硬证据，否则不得重新回到 Beam 注入、周期 face、Poisson 投影、全局电流修正或强化 FCT 等已经排除的方向。

主要证据来源：

- `output/probe_3fs/`、`output/probe_12fs/` 的 checkpoint A/B/C/D 审计；
- `output/upar_dual_audit/checkpoint_3fs/`；
- `output/upar_dual_audit/checkpoint_12fs/`；
- `output/upar_dual_audit/checkpoint_12fs/seam_targeted_fct/`；
- `output/background_coupling_upar_transpose_*.result`；
- `docs/18fs正式长跑问题与根因分析.md`；
- `results/更换为柱坐标系，优化能量闭合和离散一致性/` 与 `noCollision_*` 的宏观对比。

## 2. 当前最终结论

### 2.1 宏观物理与离散能量必须分开判断

截至 18 fs，当前程序的核心电场、背景密度、Beam 密度和总电流与 EPOCH 处于相同量级，主波包位置和主要非线性结构也较接近。因此：

- 当前核心低阶矩物理不能判定为整体错误；
- 不能为了让能量账更漂亮而重写已经有效的 x 连续性通量或 Ampere 电流；
- 任何新离散都必须以不破坏现有宏观波形为第一约束。

与此同时，全局额外能量到 18 fs 已约占总能量的 12%，中点迭代和真实子步数持续恶化。这说明：

- 当前长期能量演化仍不可信；
- 部分数值误差尚未强烈投影到主 Langmuir 模，或在低阶矩上暂时抵消；
- “宏观波形暂时接近”不能替代离散能量闭合。

### 2.2 已定位的数学问题

背景密度更新和 Ampere 使用的电流是 x-face 最终相空间通量的速度矩：

\[
J_{N,f}=q\sum_{j,k}F^{\rm final}_{x,f,j,k}.
\]

背景速度受力产生的离散动能交换由 u-face 通量构成：

\[
J_{E,i}=\frac{q}{m_ec\,\Delta x}
\sum_{j_f,k}\Delta K_{j_f,k}C^{\rm final}_{u,i,j_f,k}.
\]

映射到 Yee face 后：

\[
(G^*J_E)_{i+1/2}=\frac{J_{E,i}+J_{E,i+1}}{2}.
\]

当前基础不闭合量为：

\[
R_{\rm couple}=\Delta t\Delta x
\sum_{f\in\rm unique}E_f
\left[J_{N,f}-(G^*J_E)_f\right].
\]

现有证据表明：

1. `J_N` 与背景密度更新严格同源，必须保留；
2. `G/G*` 本身满足周期离散伴随；
3. x/u high 通量读取同一中点状态和同一中点场；
4. limiter 后最终通量已经重新用于电流矩；
5. 主要剩余误差来自 `u_parallel` 面重构、离散动能差和 x 电流矩没有由同一个离散求和分部关系导出；
6. 边界强梯度把这一基础误差放大，但不是其数学起点。

### 2.3 已确定的下一步

不再增加通用周期审计。下一步进入独立 `dual_u_coupling` 原型：

- 保持 x high 通量和 `J_N` 不变；
- 保持 Yee Ampere、Beam、周期拓扑和 `G/G*` 不变；
- 从生产 `u_parallel` 通量的真实离散算子出发，构造其动能矩与 `J_N` 对偶的新 u-face 系数；
- 新电流不能是事后修正量，必须来自真正更新背景分布和动能的 u-face 通量；
- legacy 路径必须完整保留，原型未通过回归前不得成为默认路径。

## 3. 不得破坏的正确部分

以下内容已有直接测试或宏观证据支持，必须冻结：

1. `Ex_face/Jx_face` 的 Yee face Ampere 推进；
2. Ampere 使用背景最终 x 通量形成的连续性电流 `J_N`；
3. 背景密度与 `J_N` 的有限体积离散连续性；
4. Beam 普通 pusher、轨迹电流沉积、左端注入和左右开放出流；
5. Beam 电流不周期回卷，场 ghost 按 periodic 同步；
6. 周期唯一面 ownership 和 face N 作为 face 0 alias 的拓扑；
7. `G/G*` 的周期离散伴随关系；
8. FCT 后使用最终共享面通量重新形成密度、电流和功矩；
9. 当前核心 x high/MUSCL 响应；
10. checkpoint/restart、固定候选态和 Beam dt/2 账本；
11. 当前 18 fs 前与 EPOCH 接近的核心 Ex、n_bkg、Beam 和总电流基线。

## 4. 宏观基线与尚存问题

### 4.1 当前可保留的宏观响应

18 fs 正式长跑表明：

- 核心电场主波包和 EPOCH 高度接近；
- 15 fs 核心最大场约 `15.39 E0`，EPOCH 图中约 `14.8 E0`；
- 背景密度波长、包络和主要压缩/稀疏结构处于同一量级；
- Beam 前沿速度、聚束强度和非线性区域长度相近；
- 总电流量级和主要结构相近。

这组结果是后续原型的不可破坏基线，不允许仅凭能量残差下降就接受明显偏离这些宏观量的新格式。

### 4.2 仍然存在的宏观差异

当前差异主要位于：

- `0.2-0.8 um` 近左边界区域的低幅波动比 EPOCH 更不规则；
- 右端近边界出现 EPOCH 核心区中不明显的噪声包；
- 当前边界电场尖峰明显强于内部主波包；
- 背景边界密度峰值比 EPOCH 小数倍；
- 长期额外能量持续增长；
- 中点迭代经常软接受，真实子步数增加，性能下降。

边界单点本身不是本项目要对齐的物理量，但边界数值误差不能继续拖慢全局求解，也不能通过背景周期输运进入近边界物理区和核心区。

## 5. 审计结果的有效性层级

### 5.1 `passes=1` 的正确解释

不同测试中的 `passes=1` 只表示对应审计数据完整且其自身数值检查通过，不等于“物理离散已经闭合”。必须分别读取：

- `direct_work_valid`：实际生产通量的功残差可重构；
- `seam_upar_audit_valid`：按 u 分解可以重构原面电流；
- `frozen_jacobian_valid`：冻结分支 Jacobian 测试有效；
- `active_fully_covered_fraction`：活跃支撑区覆盖率；
- `truncation_dominated/structural_plateau`：仅对相应有效输入成立。

### 5.2 12 fs 定向审计有效

12 fs `seam_targeted_fct` 满足：

- `state_advanced=1`；
- `operator_failed=0`；
- `outputs_finite=1`；
- `substeps_used=5`；
- `substep_seam_audit_valid=1`；
- `seam_upar_audit_valid=1`；
- u 分解重构相对误差 `6.99279e-15`。

因此 `seam_substeps.dat`、`seam_upar_substeps.dat` 和 `seam_upar_zones.dat` 可以用于根因判断。

`velocity_resolved_audit_valid=0` 和 `audit_inconclusive=1` 只说明旧的单子步完整 Jacobian 审计不适用于五子步 checkpoint，不否定新增的直接逐子步分解。

### 5.3 制造态收敛与形式 Jacobian 必须拆开

根目录三档制造态结果中，实际 `pair_work_L2` 为：

\[
1.35268\times10^{-7}
\rightarrow3.53957\times10^{-8}
\rightarrow6.81988\times10^{-9},
\]

观测阶约为 `1.93` 和 `2.38`。这可靠地说明当前平滑制造态的实际功残差具有近二阶截断收敛趋势。

但同时：

- `gR_work_relative` 始终约为 `0.98-0.99`；
- `Nu=96` 的 `active_fully_covered_fraction=0.922374`，低于目标 `0.999`；
- `Nu=96` 的 `kink_active_mass_fraction=0.295038`。

所以：

- 可以使用三档结果判断实际功残差的收敛趋势；
- 不能把 `all_inputs_pass=1` 解读为冻结 Jacobian 已在所有分辨率严格有效；
- 后续测试代码应拆成 `direct_pair_convergence_valid` 与 `jacobian_transpose_valid`；
- 不得根据当前 `gR_work_relative` 单独设计生产修正。

## 6. 已确认正确或已排除的机制

### 6.1 固定中点生产算子重放

3 fs 和 12 fs checkpoint 审计确认：

- 使用生产通量内核，而不是测试复写公式；
- `J_N/J_E/G*J_E` 和 Beam current 可以从保存的最终通量重放；
- 周期唯一面被恰好统计一次；
- 逐面积分能够重构全局配对残差；
- failed trial 不会被伪装为已推进状态。

### 6.2 周期 face 与 MPI ownership

单 rank、80 rank 和真实 checkpoint 共同确认：

- `unique_owned_face_count=nx`；
- face N 是 face 0 的右端 alias，不是独立场自由度；
- `JN(face0)=JN(aliasN)`；
- `G*JE(face0)=G*JE(aliasN)`；
- `G/G*` 最坏相对伴随误差约为 `2.2e-16`。

12 fs 定向同步结果：

- `seam_owned_JN_sync_linf=0`；
- `seam_owned_GstarJE_sync_linf=0`；
- `seam_alias_JN_sync_linf=2.65106e15`；
- `seam_alias_GstarJE_sync_linf=0`。

alias 上的大变化是 FCT 更新后、周期闭合前的陈旧 ghost 值被 face 0 最终值覆盖。它不是独立物理面，不能作为接缝错误证据。

结论：不修改周期 ownership、guard 合并或 Yee face 拓扑。

### 6.3 时间层与同一中点状态

状态 hash 和场 hash 证明：

- x/u high 使用同一 Picard 中点状态；
- u low/high 使用同一中点场；
- x 自由输运不读取电场，因此 `x_low_field_hash=0` 是正常现象；
- 未发现可解释当前残差的半步时间层滞后。

### 6.4 FCT 后矩重算

受控 FCT 和 checkpoint 审计确认：

- final x/u 通量同时用于背景更新和矩计算；
- `J_N/J_E/G*J_E` 相对最终通量的重放误差处于舍入量级；
- 不存在“先算电流、后缩放通量但未重算电流”的旧问题。

### 6.5 Beam 不是当前根因

Beam 连续性约为 `1e-12` 或更小，注入/出流账本和 dt/2 一致性已通过；Beam 前沿及聚束又与 EPOCH 接近。因此不再修改 Beam 注入、开放出流或轨迹电流。

## 7. 3 fs 与 12 fs 的同层残差分解

最终残差可以分为：

\[
R_{\rm final}=R_{\rm low}
+\Delta R_{x,\rm high}
+\Delta R_{u,\rm center}
+\Delta R_{x,\rm FCT}
+\Delta R_{u,\rm FCT}.
\]

| 项目 | 3 fs `[J/m2]` | 12 fs `[J/m2]` |
|---|---:|---:|
| `R_pair_low` | `-9.05097e3` | `-5.67126e5` |
| `R_pair_high` | `-1.17325e3` | `-5.50242e4` |
| `R_pair_FCT_correction` | `-1.51983` | `+4.98283e2` |
| `R_pair_final` | `-1.17477e3` | `-5.45259e4` |
| `production_r_couple` | `-1.17599e3` | `-5.45744e4` |

可得：

1. donor-cell low-order 残差远大于 high/final；
2. x high 与 u center 消除了大部分 low-order 不一致；
3. 全局退化为 donor-cell 会同时增大耗散和配对残差；
4. 3 fs FCT 改变量约占最终残差 `0.13%`；
5. 12 fs FCT 改变量约占最终残差 `0.91%`；
6. FCT 会局部重塑误差，但不是基础不闭合的起点。

因此禁止把全局增强 limiter、扩大 donor-cell 区域或关闭所有高阶修正作为能量修复。

## 8. 空间局域化与周期邻近区

### 8.1 残差集中于边界强梯度区

3 fs 的两端区域约占全局 signed 残差的 `99.90%`；12 fs 约占 `99.88%`。12 fs 的 `wave_core` signed 残差较小，但 L1 不为零，说明核心局部仍有正负抵消。

12 fs `by_x.dat` 中：

- cell 1 的 high 配对功约 `-1.36892e4 J/m2`；
- cell 3999 约 `-1.36999e4 J/m2`；
- cell 0 约 `-1.21129e-1 J/m2`。

最大残差不在周期唯一面，而在其两侧强梯度 cell。

### 8.2 强梯度是放大器而非接缝错误

强梯度平移制造态表明：把梯度从接缝平移到域内后，L1/L2/Linf 基本不变，残差剖面跟随梯度移动。结合物理面同步差为零，可以排除“face 0 特殊实现制造残差”。

### 8.3 五个真实子步

12 fs high 层的大残差从第 0 个子步就存在，并在五个子步中基本不变。`seam_pair_substep_jump_linf=4.55154e14 A/m2` 出现在 substep 3、face 3999，但仅是 final/FCT 层的小幅变化，不是基础 high 残差首次产生。

结论：

- 不修改子循环顺序；
- 不通过增减真实子步数修复基础配对；
- FCT 和子步只改变局部 final 值，不能解释 high 层起始残差。

## 9. 12 fs 的 `u_parallel` 速度区定位

### 9.1 分解定义与自校验

对 face 1 和 face 3999，把每个内部 u-face 的功电流贡献各一半分给相邻两个 u cell，使：

\[
\sum_jJ_{N,j}=J_N,
\qquad
\sum_j(G^*J_E)_j=G^*J_E.
\]

重构相对误差为 `6.99279e-15`，所以分区不会改变总电流，也不是人为能量分配。

速度区固定为：

1. `u_endpoint`：`j=0,Nu-1`；
2. `low_u`：非端点且 `|u_parallel|<=0.1`；
3. `thermal_body`：`0.1<|u_parallel|<=1`；
4. `high_u`：非端点且 `|u_parallel|>1`。

### 9.2 high 层 L1 贡献

| 区域 | high L1 `[J/m2]` | 比例 |
|---|---:|---:|
| `u_endpoint` | `3.26e-31` | 约 0 |
| `low_u` | `1.17982e3` | `2.55%` |
| `thermal_body` | `2.95008e4` | `63.77%` |
| `high_u` | `1.55805e4` | `33.68%` |

signed 汇总为：

- `low_u = +37.30 J/m2`；
- `thermal_body = -1.22247e4 J/m2`；
- `high_u = -1.52037e4 J/m2`。

L1 上 thermal body 主导；signed 上 thermal body 与 high-u 都重要。

### 9.3 最大贡献速度位置

最大贡献集中在：

\[
u_\parallel\approx
\pm0.81,\ \pm0.92,\ \pm1.04,\ \pm1.19.
\]

因此：

- 不是 `u=0` 奇异问题；
- 不是速度端点问题；
- 不是分布几乎为零的远端空尾部；
- `high_u` 贡献主要来自靠近 `|u|=1` 的活跃超热肩部，不能裁掉；
- 修复必须覆盖热主体和近 `|u|=1` 活跃区。

### 9.4 FCT 在速度区中的作用

thermal body 和 high-u 的 high/final 值几乎相同；FCT 差异主要位于 low-u。由此确认：

- thermal/high-u 基础配对误差存在于 high 层；
- FCT 不是这些主要贡献的来源；
- 调整 low-u limiter 不会解决主要能量缺口。

## 10. 制造态和方向分离结果

### 10.1 x 方向

在只加密 x、固定速度网格和物理 dt 的实验中，裸 `J_N-G*J_E` 残差没有随 x 加密显著降低。周期平移和单/多 rank 测试又排除了特殊接缝误差。

结论：x 网格分辨率和 face ownership 不是基础根因。

### 10.2 `u_perp` 方向

只加密 `u_perp` 基本不改变主要配对残差。

结论：当前问题不由 `u_perp` 分辨率或柱坐标 ring 面积单独控制。

### 10.3 `u_parallel` 方向

只加密 `u_parallel` 时，实际功残差显著下降；三档制造态 `pair_work_L2` 呈近二阶收敛。

结论：基础误差由有限 `u_parallel` 离散的通量/动能配对控制。

但生产不能依赖盲目增加 `Nu`：

- 计算成本和内存会显著增加；
- 中点迭代和 FCT 成本同步上升；
- 加密只能用来识别误差性质，不能作为最终修复。

## 11. 共同速度 A/B 实验与否定方向

曾尝试把 x high 通量的解析 `v_x` 直接替换为当前 `energy_consistent_cell_speed_candidate()`。受控四样本 A/B 表明局部功残差扩大约 `2.43` 倍。

这说明：

- 正确修复不是把某个 u-face 能量速度简单平均成 x cell 速度；
- x MUSCL Jacobian、u-face 重构、`delta_K`、非均匀网格距离和柱坐标权重必须整体进入离散对偶推导；
- 不能修改 x 物理输运速度来迁就现有 u 功矩。

明确禁止：

- 用 `G*J_E` 覆盖 Ampere 的 `J_N`；
- 从全局能量余额反解一个人工电流；
- 每步扣除电流零模或强制 `mean(E)=0`；
- 每步 Poisson 投影；
- 直接替换 x high 的解析速度；
- 只修改诊断 `J_E` 而不修改 u 更新；
- 边界裁剪 Ex/J/n；
- 全局强化 FCT 或 donor-cell。

## 12. 更新后的完整根因链

当前与全部证据一致的根因链为：

1. x 最终相空间通量严格更新背景密度并形成 `J_N`；
2. `J_N` 进入 Yee face Ampere，维持正确的背景连续性和主要低阶矩响应；
3. u-face 受力通量通过 `delta_K` 形成背景离散动能功 `J_E`；
4. x high 电流矩和 u high 功矩虽然读取同一中点态，但没有由同一个离散求和分部恒等式共同导出；
5. 有限 `Nu` 下，thermal body 和近 `|u|=1` 活跃区产生 `J_N-G*J_E`；
6. 平滑制造态中该实际功误差随 `Nu` 近二阶降低，说明它主要表现为有限网格截断/配对误差；
7. 在生产边界强场和强梯度下，同一误差被放大到主要空间残差；
8. FCT 只在 low-u 和局部强梯度处重塑 final 结果，不是 high 层根因；
9. Ampere 按 `J_N` 积分场能，而背景动能按 `J_E` 变化，二者差额逐步累积为数值能量；
10. 额外能量优先进入背景高阶速度矩、边界噪声和非主模，因此 18 fs 前核心低阶波形仍可接近 EPOCH；
11. 随非线性增强，配对误差、真实子步和中点残差增大，最终导致性能下降和长期可信度降低。

根因的最精确表述是：

> 当前生产 high 层的 `u_parallel` 受力通量动能矩，与 x 连续性电流矩在 thermal body 和近 `|u_parallel|=1` 活跃区中不是严格离散对偶。边界强梯度是主要空间放大器，FCT 是次要局部重塑项，周期接缝、Beam 和 `G/G*` 不是根因。

## 13. 审计阶段结论与停止条件

通用审计已经完成。以下内容不再重复：

- 周期 face ownership/alias；
- 单 rank/80 rank `G/G*`；
- x/u 同一中点状态 hash；
- FCT 后矩重算；
- 强梯度平移；
- x、`u_parallel`、`u_perp` 方向分离；
- 简单共同速度 A/B；
- 3 fs/12 fs low/high/final 分层；
- 12 fs 五子步周期邻近区和 u 分区。

仅需修正测试语义，不需要再进行新的 fs 长跑：

1. 把 `passes` 拆成 `direct_pair_convergence_valid` 和 `jacobian_transpose_valid`；
2. `jacobian_transpose_valid` 必须强制所有输入满足活跃覆盖率门槛；
3. 不得让 `Nu=96` 的 `0.922374` 覆盖率继续被汇总为完整 Jacobian 通过；
4. 保留现有结果作为 direct pair 收敛证据，不用重跑 12 fs checkpoint。

完成上述测试语义修正后，停止增加同类诊断，进入原型实现。

## 14. `dual_u_coupling` 原型设计

### 14.1 双路径和功能开关

必须保留：

- `legacy_coupling`：当前默认生产路径；
- `dual_u_coupling`：新的 u 功矩对偶原型。

原型不得覆盖 legacy 函数或通过条件编译删除旧路径。使用运行时或构造参数选择，当前默认为 dual-u，legacy 仅作显式回退和 A/B 对照路径。

### 14.2 固定 x 连续性通量

原型第一阶段保持：

\[
F_x^{\rm high},\quad
F_x^{\rm final},\quad
J_N=q\sum F_x^{\rm final}
\]

全部不变。

理由：

- `J_N` 与背景密度更新严格连续；
- 核心宏观波形证明当前 x 物理输运基本有效；
- 直接替换 x 速度已被 A/B 否定。

### 14.3 从真实生产算子导出目标权重

在固定中点态 `M` 和固定 `E_mid` 上定义：

\[
W_N(M)=\Delta t\Delta x\sum_fE_fJ_{N,f}(M),
\]

\[
W_E(M)=\Delta t\Delta x\sum_iE_iJ_{E,i}(M)+B_u^K(M).
\]

目标不是比较解析 `v_x` 与手写能量速度，而是比较实际生产离散泛函的局部权重：

\[
w_N=\frac{\partial W_N}{\partial M},
\qquad
w_E=A_u^T\frac{\Delta K}{m_ec\Delta x}.
\]

其中 `A_u` 必须来自生产 u-face 重构的真实固定分支算子，包含：

- 非均匀 `u_parallel` 网格距离；
- `u_perp` ring 面积；
- 场到 cell 的 `G`；
- 柱坐标质量权重；
- u 边界通量和 `B_u^K`；
- 实际 center/high 重构 stencil。

### 14.4 新 u-face 算子的约束

构造局部 `A_{u,new}`，使：

\[
A_{u,new}^T\frac{\Delta K}{m_ec\Delta x}
\approx w_N,
\]

并同时满足：

1. u 更新仍是共享面通量差，严格守恒背景粒子数；
2. 修正 stencil 局部，不依赖全局能量余额；
3. 零场时 u 通量严格为零；
4. 正负场满足奇对称；
5. 均匀 Maxwellian 不产生人工漂移；
6. u 端点功账显式保留；
7. 不改变 `J_N`、Beam、Ampere、`G/G*`；
8. thermal body 和近 `|u|=1` 活跃区都进入约束；
9. 不通过裁掉 high-u 活跃贡献获得闭合；
10. 不要求每个速度 cell 单独严格能量匹配到牺牲物理解，优先保证共享面守恒、局部 L1/L2 降低和宏观回归。

### 14.5 不允许事后电流修正

新 `J_E` 必须由真正用于更新 `f` 的 `C_{u,new}` 形成：

\[
J_{E,new}=\frac{q}{m_ec\Delta x}
\sum\Delta K\,C_{u,new}.
\]

禁止：

- 在 u 更新完成后单独修改 `J_E`；
- 在 Ampere 前对 `J_N` 做投影；
- 添加一个只闭合全局 signed 余额的常数电流；
- 用诊断残差直接回填场。

### 14.6 若局部 u 对偶不可行

如果不存在同时局部、守恒、稳定且不破坏波形的 `A_{u,new}`，应停止该原型，再考虑 `joint_xu_coupling`。不得继续叠加补丁。

联合原型必须同时满足：

\[
\frac{n_i^{n+1}-n_i^n}{\Delta t}
+\frac{J_{N,i+1/2}-J_{N,i-1/2}}{q\Delta x}=0,
\]

\[
\Delta K_{\rm bkg}-B_u^K
=\Delta t\Delta x\sum_fE_fJ_{N,f}
+O(\Delta t^p+\Delta x^q).
\]

只有 `dual_u_coupling` 明确失败后才允许进入联合重构。

## 15. 实施顺序

### 15.1 阶段 0：修正审计通过语义

2. 增加 `jacobian_transpose_valid`；
3. Jacobian 通过必须要求每一档活跃覆盖率 `>=0.999`；
4. `Nu=96` 当前结果应标记 Jacobian 不完整，但 direct pair 有效；
5. 汇总文件不得再用一个 `passes` 同时代表两种结论。

### 15.2 阶段 1：无 FCT、无 Beam 的中心原型

1. 新增 `dual_u_coupling` 功能开关；
2. 抽出生产 `A_u` 固定分支算子；
3. 导出 `w_E=A_u^T\Delta K/(mc\Delta x)`；
4. 从真实 x 通量泛函导出 `w_N`；
5. 构造局部 `A_{u,new}`；
6. 用同一 `C_{u,new}` 更新分布并计算 `J_E`；
7. 首先只运行平滑、无 Beam、无 FCT、固定中点态测试。

### 15.3 阶段 2：基础离散测试

依次测试：

1. 零场 Maxwellian；
2. 正/负微小均匀电场；
3. 空间相位 0 和四分之一周期；
4. 非均匀柱坐标速度网格；
5. `Nu=48/96/192` 制造态；
6. u 端点非零通量的人造测试；
7. 单 rank/多 rank 一致性。

每个测试必须输出：

- 质量误差；
- 动量误差；
- u 边界功；
- `J_N-G*J_E` 的 signed/L1/L2/Linf；
- 正负场对称误差；
- 分布最小值，但有限负值不能单独否定原型；
- legacy 与 dual 的差值。

专项判据必须按物理可适用范围分开，不能用一个普通相对
`dual_decomposition_pass` 否决所有测试：

1. 零场 Maxwellian 直接检查最终分布相对初态的漂移、实际 u-face 通量和
   `J_N/sum|q v_x f/dx|`。零场近零目标的 cell 对偶相对误差仅作诊断。
2. 正负微小场必须先逐速度单元组成
   `f(+E)+f(-E)-2f(0)`，再按固定 rank 顺序求动量矩；禁止先归约三个大动量
   再相减。完整状态和实际 u 通量的奇对称是主判据。
3. 端点人造测试必须独立重建
   `Delta K+(Psi^K_x,R-Psi^K_x,L)+B_u^K-dt*dx*sum(E*J_E)`，并另用生产
   `delta_ke_bkg`、`stage5_u_energy_moment`、x 空间边界项和 `B_u^K` 重构
   `R_FV`。还要分别验证独立/生产 `Delta K` 同源，以及 u 功矩与完整步
   `je_final` 同源。只含内部 u-face 的普通对偶分解不适用于非零端点通量。
4. 制造态汇总器是串行文件聚合程序，必须单进程运行，并拒绝 PMI/PMIx
   环境中大于 1 的进程数，防止并发覆盖同一结果文件。

### 15.4 阶段 3：接回 MUSCL 与 FCT

顺序：

1. center/high，无 limiter；
2. MUSCL 固定分支；
3. low-order 稳定底座；
4. FCT 共享面 alpha；
5. 检查 limiter 后 `C_{u,new}` 是否仍同时进入更新和功矩；
6. 检查 FCT 激活率和 donor-cell 退化率。

若接入 FCT 后 only-final 残差重新增大，而 high 原型仍闭合，只修 FCT 后同源通量，不回头修改 center/high 原型。

### 15.5 阶段 4：checkpoint A/B

1. 3 fs 固定中点 checkpoint 单步；
2. 12 fs 固定中点 checkpoint 五真实子步；

4. 特别检查 face 1/3999 的 thermal body 与近 `|u|=1`；
5. 检查核心 Ex/n/J 候选态差异；
6. 不需要新的 18 fs checkpoint。

12 fs 五子步审计使用生产算子逐真实子步保存的
`JN_by_u` 与 `GstarJE_by_u`，输出：

- `multisubstep_upar_pair.dat`：逐 `u_parallel` 的 high/final signed、L1、L2、Linf；

- `fct_physical_weighted_coverage.dat`：按背景质量、`|q v_x|` 电流矩和动能矩

`multisubstep_upar_final_minus_production` 必须在求和舍入误差内，证明逐速度分解

## 16. 验收门槛

### 16.1 离散正确性

新原型必须满足：

1. 背景总粒子数守恒不退化；
2. x 连续性和 `J_N` 完全不变；
3. u-face 共享通量在相邻 cell 间严格反对称；
4. u 边界功账闭合；
5. 零场 Maxwellian 不漂移；
6. 正负微小场响应对称；
7. `G/G*` 和周期 ownership 回归继续通过；
8. Beam 12.5/12.6 账本完全不变；
9. direct pair 分解必须从生产通量重构，不能复写另一套公式。

### 16.2 配对残差

必须同时降低：

- 全局 signed；
- 全局 L1/L2/Linf；
- 核心区 L1/L2；
- 边界强梯度区 L1/L2；
- thermal body；
- 近 `|u|=1` 活跃区。

只降低全局 signed、但局部 L1/L2 增大，判定失败。

### 16.3 宏观物理

相对 legacy：

1. 3 fs/12 fs checkpoint 核心 Ex 峰值优先控制在 `2%` 内，硬上限 `5%`；
2. `0.2-0.8 um` 的起振不得进一步被压低；
3. 主波长、主峰位置和包络不得明显改变；
4. 背景密度压缩/稀疏幅度不得系统性减弱；
5. Beam 前沿速度和聚束不得明显变化；
6. 总电流量级不得为了能量账而被压低。

### 16.4 稳定性与保正

1. 不要求所有高阶候选态逐点严格非负；
2. 最终接受态不能出现 NaN/Inf；
3. 负分布不能无限放大到影响宏观矩和中点收敛；
4. FCT 不能在核心区大面积退化到 donor-cell；
5. 边界有限负值不应单独触发全局停机；
6. FCT 是否主导物理区必须以质量、电流矩和动能矩加权覆盖率判断，不能仅以
   active cell 点数判断；低密度尾部的高点数覆盖率应单列，不得冒充核心物理退化。

### 16.5 阶段 4 收敛状态

阶段 4 保留两级、不可混淆的验收：

1. `stage4_strict_endpoint_pass=1`：legacy 和 dual 均为
   `strict_converged`，宏观门槛通过，且 dual 迭代数未增加。这也是旧字段
   `stage4_final_endpoint_pass` 的唯一通过条件。
2. `stage4_matched_soft_comparison_pass=1`：legacy 和 dual 均为
   `soft_accepted`，宏观门槛通过，且 dual 迭代数未增加。它只说明同一软接受等级下
   A/B 对照有效，不得改称严格收敛；必须再做从该 checkpoint 开始的生产短跑确认。

`stage4_comparable_endpoint_pass` 可由上述任一级触发；若仅第二级通过，必须同时有
`stage4_requires_production_short_run_confirmation=1`。不得通过放宽生产中点容差来
制造 12 fs 的“严格通过”。
6. 边界误差进入核心必须由 buffer/core 诊断检测。

### 16.5 性能

1. 关闭详细审计后不得保留逐 u/逐 face 大数组；
2. fixed-candidate 审计通信不得进入正式长跑；
3. 原型单步成本应优先控制在 legacy 的 `1.5` 倍以内；
4. 真实子步和中点迭代次数不能系统性增加；
5. 不允许通过增加生产 `Nu` 获得通过结果。

## 17. 失败停止条件

出现以下任一情况，停止 `dual_u_coupling` 分支并回到离散推导，不增加修补层：

- 能量账改善但核心 Ex/n/J 明显变差；
- `0.2-0.8 um` 起振进一步被压制；
- thermal body 或近 `|u|=1` 的局部 L1/L2 增大；
- 只有全局 signed 余额变小；
- 使用了人工电流、全局投影或场回填；
- 大量面退化到 donor-cell；
- 中点迭代、子步数或计算成本明显恶化；
- 新格式依赖强化保正才能运行；
- 3 fs checkpoint 已明显偏离 legacy。

## 20. 最终判断

目前不再需要继续寻找周期接缝或 Beam 边界错误。全部直接审计共同指向：

> x 连续性电流保持了正确的背景密度和 Ampere 低阶矩通道，但生产 high 层的 `u_parallel` 受力功矩在 thermal body 和近 `|u_parallel|=1` 活跃区中没有与该电流形成严格离散对偶。有限 `Nu` 使误差表现为可收敛的截断/配对误差，边界强梯度再将其放大并长期积累成数值能量。

因此，后续唯一主线是：

> 保留 x、Ampere、Beam 和周期拓扑，在独立开关下重构真正参与分布更新的局部 `u_parallel` 面通量，使其动能矩与 `J_N` 对偶，并用现有 EPOCH 宏观基线约束该修复不能压制真实波形。
