# 15.5 阶段 4：production legacy/dual-u checkpoint A/B

本测试只增加运行时 coupling 选择和审计。当前默认是 `dual-u`；需要 legacy A/B 时必须显式传入
`--background-coupling-mode legacy`。为便于审计，dual-u 对照命令仍建议显式传入
`--background-coupling-mode dual-u`。

`final_midpoint` 的格式为 `FPMIDPT6`。旧的 `FPMIDPT5` dump 不含本阶段所需的
真实接受场和 coupling mode，不能用于下面的 A/B 比较。

## 1. 编译

在仓库根目录执行：

```bash
cmake -S . -B build_dual_u_stage4 \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER=mpicxx \
  -DFP_BUILD_BACKGROUND_COUPLING_TESTS=ON
```

```bash
cmake --build build_dual_u_stage4 -j 16 --target fp_solver
```

```bash
cmake --build build_dual_u_stage4 -j 16 --target background_coupling_upar_checkpoint_audit
```

```bash
cmake --build build_dual_u_stage4 -j 16 --target background_coupling_stage4_ab_compare
```

## 2. 设置一次变量

以下以 80 ranks 为例。`CHECKPOINT_3FS` 和 `CHECKPOINT_12FS` 必须是同一 git
revision、同一网格、同一 80-rank 布局生成的已有 checkpoint。

```bash
BIN="$(pwd)/build_dual_u_stage4"
ROOT="$(pwd)/output/dual_u_stage4"
RUN="srun -N 10 -n 80 --ntasks-per-node=8 --cpu-bind=cores"
CHECKPOINT_3FS="/absolute/path/to/3fs_checkpoint"
CHECKPOINT_12FS="/absolute/path/to/12fs_checkpoint"
mkdir -p "$ROOT"
```

集群使用 `yhrun` 或 `mpirun` 时，只替换 `RUN`，不能改变读取 checkpoint 的 rank 数。

## 3. 3 fs A：legacy 单步

```bash
mkdir -p "$ROOT/3fs/A_legacy"
```

```bash
$RUN "$BIN/fp_solver" \
  --restart "$CHECKPOINT_3FS" \
  --background-coupling-mode legacy \
  --stop-after-steps 1 \
  --midpoint-max-iters 40 \
  --diagnostic-level 2 \
  --dump-final-midpoint \
  --output-dir "$ROOT/3fs/A_legacy" \
  > "$ROOT/3fs/A_legacy/run.out" \
  2> "$ROOT/3fs/A_legacy/run.err"
```

生成的 A 固定态输入为：

```text
$ROOT/3fs/A_legacy/final_midpoint
```

## 5. 3 fs C：重放 A 的最终中点输入

这里的 `--operator-audit` **不是**填 `CHECKPOINT_3FS`。它应填第 3 步 A 单步续跑
后新生成的 `final_midpoint`，即该次生产算子最后实际使用的中点状态。

```bash
mkdir -p "$ROOT/3fs/A_legacy/C"
```

```bash
$RUN "$BIN/fp_solver" \
  --operator-audit "$ROOT/3fs/A_legacy/final_midpoint" \
  --diagnostic-level 2 \
  --output-dir "$ROOT/3fs/A_legacy/C" \
  > "$ROOT/3fs/A_legacy/C/run.out" \
  2> "$ROOT/3fs/A_legacy/C/run.err"
```

## 14. 必查项

每个 B 的 `run.out` 应显示 `background_coupling=dual_u`；对应
`step_diagnostics.dat` 最后一列应为 `1`。A 分别应显示 `legacy` 和 `0`。

四个 C 的 `fixed_midpoint_operator_audit.result` 必须检查：

```bash
grep -E '^(background_coupling_mode|audit_finite|face_pairing_ledger_match|periodic_seam_match|coupling_layout_match)' \
  "$ROOT/3fs/A_legacy/C/fixed_midpoint_operator_audit.result"
```

`stage4_ab_comparison.result` 必须至少检查：

```text
mode_pair_valid
core_state_gate_Ex_n_2pct_J_5pct
legacy_final_strict_converged
dual_final_strict_converged
dual_final_iteration_not_increased
stage4_final_endpoint_pass
```

12 fs 五步是否存在系统性软接受或迭代增加，还需逐行比较：

```text
$ROOT/12fs/A_legacy/step_diagnostics.dat
$ROOT/12fs/B_dual/step_diagnostics.dat
```

其中包含每一步的 `soft_unconverged`、`coupled_iter_global` 和最后一列
`background_coupling_mode`。
