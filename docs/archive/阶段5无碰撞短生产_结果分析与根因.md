# 阶段5（无碰撞短生产）测试结果分析与根因报告

日期：2026-08-02
依据：`output/` 下阶段5各档输出 + `docs/开放Beam_非周期场_VPFP_PIC完整重构方案.md`（§14 阶段5、§16.7）

## 1. 结论摘要

- **3 fs 两档（dt=1.0 / 0.5）均完成，且两档高度收敛**。
- **40 fs dt=1.0 硬失败**：step 1543（t≈39.48 fs）触发 `failure_code=7`（背景速度尾部损失超阈值），
  距 40 fs 终点仅差约 20 步。
- **40 fs dt=0.5 跑完 40 fs（step 3127），但属于擦线通过**：36 fs 时域内尾部质量占比已
  ~6.9e-12 且仍在指数增长，其"通过"主要来自每步判据对 dt 的尺度依赖，不代表尾部物理已安全。
- **12 fs、25 fs 两档未运行**（详见 §5 说明）。
- **根因**：束-等离子体两流不稳定性对背景电子产生真实且持续的高能尾推；速度域外区网格
  （u≈10–20）欠解析（单元宽为核心区 100–240 倍）使尾部填充率依赖 dt；每步尾部损失阈值
  判据对 dt 尺度敏感。三者叠加导致 40 fs dt=1.0 在终点前中止。

## 6. 根因分析

### 6.1 直接触发机制

u∥ remap（T_u 子步）后检查：

```text
tail_fraction = 本步从 u=±20 流失的背景质量 / 步前总质量
tail_fraction > 1e-11  → 硬失败（failure_code=7）
```

单步流失量 ≈ 瞬时尾部通量 × dt。同一物理时刻，dt 减半则单步损失减半，所以 dt=1.0 在
39.48 fs 越过阈值，dt=0.5 压到 40 fs 之后。**dt=0.5 的"通过"是判据尺度的巧合**：
36 fs 时其域内尾部含量已 6.9e-12 且仍在增长。

### 6.2 物理根因：束-等离子体两流不稳定性的真实尾推

- 束参数：n_b ≈ 1.05e27 m⁻³、γβ=8.6（u∥≈8.6）、v≈0.993c，注入 0–25 fs；
  束在 40 µm 域内穿越时间 ≈ 134 fs——即使停止注入，束仍长时间提供自由能。
- 增长波对背景电子共振加速（ω≈k·v_ph），把电子推向高 u∥，形成尾部；这是真实物理，
  阶段4 记录已确认（"单步 a_u·dt 最大仅 0.09，非数值爆炸"）。
- 证据：场能 U_E 25–38 fs 饱和（~7e7 J/m 不增反降），但尾部质量继续指数增长——
  驱动持续、尾部持续外推，且 40 fs 内看不到饱和迹象。

### 6.3 数值放大：速度域外区欠解析

u_max=20、Nv=192 的 sinh 拉伸网格把分辨率几乎全放在核心区：

| u 位置 | 单元宽 |
|---|---|
| 0（核心） | 0.0052 |
| ~5 | 0.32 |
| ~8 | 0.51 |
| ~10 | 0.66 |
| ~12 | 0.80 |
| ~15 | 0.97 |
| ~18 | 1.17 |
| ~19.4（最外） | 1.25 |

后果：

1. 尾部所在的 u≈10–20 外区，单元宽是核心的 100–240 倍，整条尾巴只由几十个巨单元解析；
2. 外区 PPM 重构被限幅器压到常数/线性（~83% 常数 + ~8% 线性），尾部输运几乎全程一阶、
   带明显数值扩散；
3. 数值扩散随 dt 增大 → 尾部增长率系统性依赖 dt：

| 区间 | dt=1.0 增长率 | dt=0.5 增长率 |
|---|---|---|
| 18→25 fs | 1.76 decade/fs | 1.67 decade/fs |
| 25→30 fs | 0.73 | 0.66 |
| 30→36 fs | 0.63 | 0.47 |

4. 直接后果是 36 fs 时两档尾部含量差 **84 倍**、K_e 差 24%——尾部填充本身不收敛。

## 7. 问题答疑：到底发生了什么

**问：是不是产生了极少量的高能粒子，速度非常快，超出 u_max=20，流失超过阈值导致失败？**

基本正确，精确化如下：

- **极少量**：触发阈值是单步流失 > 总质量的 1e-11。总背景 ≈ 4.79e24，即触发时**一步**
  流失约 4.8e13 个电子的等效质量；36 fs 时域内 |u∥|>15 尾部占比 5.8e-10（约 2.8e15 电子
  等效），相对总量仍是万亿分之一量级——但它在指数增长（30→36 fs 涨约 6000 倍）。
- **多快**：u=20 → γ≈20、v≈0.99875c、动能 ≈ (γ−1)·0.511 MeV ≈ **9.7 MeV**。
  对比背景热电子 100 eV、束电子 3.9 MeV——尾部粒子比热背景高约十万倍能量，是相对论性的，
  但并非"极端宇宙线"级别。
- **流失机制**：u∥ remap 是保守的；质量沿 u 轴平流，越界部分不能留在域内，被计入
  `tail_number_loss` 并从计算域移除；单步占比超 1e-11 即硬停（§7.4，无重试）。
- **不是数值 bug**：这些高能电子是束-等离子体不稳定性对背景电子的真实加速结果；
  问题在速度域外区网格太粗（u≈19 处单元宽 ~1.25，为核心 240 倍），使尾巴的数量与
  形态尚未收敛，且填充率依赖 dt。

## 8. 判定与建议

### 判定

**阶段5 未通过**：

1. 40 fs dt=1.0 硬失败（failure_code=7，39.48 fs）；
2. 非线性相 dt 收敛性不达标（36 fs 尾部含量差 84 倍、K_e 差 24%）；
3. 按 dt=0.5 的尾部增长率外推，40 fs 时域内尾部含量已到 ~5e-10 量级，u_max=20 对 40 fs
   终点都只是勉强，对 120 fs 生产（束穿越 ~134 fs 全程供能）不可能够。

### 修复方向（需用户拍板）

- **扩域必须同步加密**：如 u_max=30–40，则 Nv 需加到 256–320（或采用非均匀加密），
  把外区单元压到 ~0.05 量级，使尾部输运不再依赖数值扩散。
- **判据的物理含义**：每步瞬时阈值（1e-11）对 dt 尺度敏感；可考虑改为时间窗累计或
  总尾部记账，或明确采用"高速出流按能量记账"的边界模型（后者与 §7.4 硬失败属性冲突，
  需文档级决策）。
- **补跑与可分析性**：重跑 12/25/40 fs 时建议加 `--diagnostic-interval 50`（默认 500 导致
  3 fs 等短档无逐行诊断）；40 fs 的 EPOCH 对照只取量级/增长率/包络，不做逐点拟合。
