# 15.3 阶段 2 基础离散测试：编译与运行命令

本文档给出 `15.3 阶段 2` 的独立编译、运行和结果检查命令。测试只审计 dual-u 背景耦合离散，不替换生产 `J_N`、不做能量投影，也不通过 limiter 强制闭合能量账。

## 1. 当前状态

当前代码已经提供阶段 1 预检目标：

```text
background_coupling_dual_u_center_test
```

阶段 2 所需的七类正式测试目标已加入 CMake。配置时必须显式启用
`FP_BUILD_BACKGROUND_COUPLING_TESTS=ON`，并在源码更新后重新执行 CMake 配置；
仅在旧的 build 目录中执行 `make` 不会自动获得新目标。

## 2. 环境与编译

在仓库根目录执行：

```bash
module purge
module load mpi

cmake -S . -B build_dual_u_stage2 \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER=mpicxx \
  -DFP_BUILD_BACKGROUND_COUPLING_TESTS=ON
```

先编译当前已经存在的阶段 1 预检：

```bash
cmake --build build_dual_u_stage2 -j 16 \
  --target background_coupling_dual_u_center_test
```

阶段 2 实现完成后，编译全部阶段 2 目标：

```bash
cmake --build build_dual_u_stage2 -j 16 --target \
  background_coupling_dual_u_zero_field_test \
  background_coupling_dual_u_field_symmetry_test \
  background_coupling_dual_u_phase_test \
  background_coupling_dual_u_nonuniform_grid_test \
  background_coupling_dual_u_endpoint_flux_test \
  background_coupling_dual_u_manufactured_coarse \
  background_coupling_dual_u_manufactured_base \
  background_coupling_dual_u_manufactured_fine \
  background_coupling_dual_u_convergence_audit \
  background_coupling_dual_u_mpi_consistency_test \
  background_coupling_dual_u_mpi_consistency_audit
```

若只需编译 5.4，执行：

```bash
cmake --build build_dual_u_stage2 -j 16 --target \
  background_coupling_dual_u_nonuniform_grid_test
```

编译前可先确认目标已进入当前 build 目录：

```bash
cmake --build build_dual_u_stage2 --target help | \
  grep background_coupling_dual_u_nonuniform_grid_test
```

若没有任何输出，说明该 build 目录没有使用当前源码重新配置。重新执行本节开头的
`cmake -S . -B build_dual_u_stage2 ...` 命令后再编译。

若集群使用 `make`，等价命令为：

```bash
cd build_dual_u_stage2
make -j 16 background_coupling_dual_u_center_test
cd ..
```

不要在目标尚未加入 CMake 时运行阶段 2 的 `make` 命令，否则会得到 `No rule to make target`。

## 3. 输出目录

为本批测试创建独立目录：

```bash
mkdir -p output/dual_u_stage2
```

阶段 2 正式目标应支持：

```text
--output-dir <directory>
```

每个测试目录至少包含：

```text
summary.result
run.out
run.err
```

三档制造态还应保留各自的逐档结果，汇总结果写入：

```text
output/dual_u_stage2/manufactured_convergence/summary.result
```

## 4. 阶段 1 预检

该目标当前已经可以编译运行。它编译为
`Nx=800, Nupar=96, Nuperp=64`，并连续执行一次 legacy 算子和一次
dual-u 算子，因此不应使用单 rank 作为正式预检。建议使用与生产作业
一致的 MPI 空间分解；以下以 80 ranks 为例：

```bash
mkdir -p output/dual_u_stage2/stage1_precheck

srun -N 10 -n 80 --ntasks-per-node=8 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_center_test \
  > output/dual_u_stage2/stage1_precheck/run.out \
  2> output/dual_u_stage2/stage1_precheck/run.err
```

若集群使用 `yhrun`，只替换启动器：

```bash
yhrun -N 10 -n 80 --ntasks-per-node=8 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_center_test \
  > output/dual_u_stage2/stage1_precheck/run.out \
  2> output/dual_u_stage2/stage1_precheck/run.err
```

节点数和每节点进程数应按实际资源调整，但总 MPI ranks 不应超过
`Nx=800`，并应避免 MPI/OpenMP 超额订阅。该测试没有逐阶段进度输出：
只有 legacy 与 dual-u 两次算子评估全部结束后，rank 0 才会写入
`output/background_coupling_dual_u_center_test.result`，并向标准输出打印
最终一行。因此运行期间 `.out` 为空本身不表示程序卡死。

阶段 1 预检必须先满足：

```text
passes=1
fx_high_max_abs_difference=0
j_n_high_max_abs_difference=0
```

## 5. 阶段 2 正式测试

以下命令应分别提交，本文档不提供自动提交脚本。

### 5.1 零场 Maxwellian

```bash
mkdir -p output/dual_u_stage2/zero_field

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_zero_field_test \
  --output-dir output/dual_u_stage2/zero_field \
  > output/dual_u_stage2/zero_field/run.out \
  2> output/dual_u_stage2/zero_field/run.err
```

零场验收不再用接近零的 `J_N` 作为普通相对误差分母。必须直接检查：

```text
zero_field_state_relative_L2 <= 1e-14
zero_field_u_flux_Linf = 0
zero_field_JN_relative_to_cancellation_scale <= 1e-12
zero_field_pass = 1
```

其中 `zero_field_cancellation_current_scale` 由同一离散 Maxwellian 的
`sum |q vx f/dx|` 构造，用于判断正负速度积分消减后的残余 `J_N`。零场下
`dual_cell_JE_minus_target_relative_L2` 仅保留为诊断，不参与通过判定，因为
零场 u 通量为零，近零目标的纯相对分解没有物理验收意义。

### 5.2 正负微小均匀电场

该测试应在同一次执行中使用完全相同的 Maxwellian，分别计算 `+E` 和 `-E`：

```bash
mkdir -p output/dual_u_stage2/field_symmetry

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_field_symmetry_test \
  --output-dir output/dual_u_stage2/field_symmetry \
  > output/dual_u_stage2/field_symmetry/run.out \
  2> output/dual_u_stage2/field_symmetry/run.err
```

必须检查正负场响应的奇偶对称性，不能分别随机初始化两次。动量奇对称量
必须先对 `f(+E)-f(0)` 与 `f(-E)-f(0)` 逐速度单元组成响应，再按 rank 固定
顺序求和；禁止先分别对三个大动量做 MPI 归约后相减。结果中必须包含：

```text
field_symmetry_momentum_odd_absolute
field_symmetry_momentum_response_scale
field_symmetry_momentum_roundoff_scale
field_symmetry_momentum_odd_relative
field_symmetry_state_odd_relative
field_symmetry_u_flux_odd_relative
field_symmetry_JN_even_relative
field_symmetry_GstarJE_even_relative
```

近零电流的 `dual_decomposition_pass` 不参与该专项通过判定；完整状态、实际
u-face 通量和电流响应的奇偶对称性才是主判据。

### 5.3 空间相位 0 与四分之一周期

```bash
mkdir -p output/dual_u_stage2/phase

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_phase_test \
  --output-dir output/dual_u_stage2/phase \
  > output/dual_u_stage2/phase/run.out \
  2> output/dual_u_stage2/phase/run.err
```

测试内部应运行相位 `0` 和 `pi/2`，将第二组结果周期平移回第一组后再比较，不应只比较两个全局标量。

### 5.4 非均匀柱坐标速度网格

非均匀网格不是单独切换成均匀网格的 A/B 测试；零场、场对称、相位和制造态测试都必须使用生产配置中的非均匀 `(u_parallel,u_perp)` 网格，并在每份 `summary.result` 中写出：

```text
velocity_grid_nonuniform=1
Nupar=<value>
Nuperp=<value>
upar_grid_hash=<value>
uperp_grid_hash=<value>
```


若任一阶段 2 结果缺少这些字段，该测试批次不能作为非均匀网格验收结果。

独立网格审计命令为：

```bash
mkdir -p output/dual_u_stage2/nonuniform_grid

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_nonuniform_grid_test \
  --output-dir output/dual_u_stage2/nonuniform_grid \
  > output/dual_u_stage2/nonuniform_grid/run.out \
  2> output/dual_u_stage2/nonuniform_grid/run.err
```

三档应分别提交，不能在一个 MPI 作业中串联运行。

粗档：

```bash

  > output/dual_u_stage2/manufactured_coarse/run.out \
  2> output/dual_u_stage2/manufactured_coarse/run.err
```

生产档：

```bash
mkdir -p output/dual_u_stage2/manufactured_base

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_manufactured_base \
  --output-dir output/dual_u_stage2/manufactured_base \
  > output/dual_u_stage2/manufactured_base/run.out \
  2> output/dual_u_stage2/manufactured_base/run.err
```

细档：

```bash
mkdir -p output/dual_u_stage2/manufactured_fine

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_manufactured_fine \
  --output-dir output/dual_u_stage2/manufactured_fine \
  > output/dual_u_stage2/manufactured_fine/run.out \
  2> output/dual_u_stage2/manufactured_fine/run.err
```

```bash
mkdir -p output/dual_u_stage2/manufactured_convergence

  output/dual_u_stage2/manufactured_coarse/summary.result \

```

该汇总器是串行文件聚合程序，必须直接执行或使用 `srun -N 1 -n 1`。不得用
`srun/yhrun -n 80` 启动；程序会通过 PMI/PMIx/OMPI/MVAPICH 环境检测并拒绝
多进程启动，避免多个进程并发覆盖同一个 `summary.result`。

汇总器必须拒绝混用不同 `git_revision`、`git_dirty`、网格哈希或测试配置的结果。

### 5.6 u 端点非零通量人造测试

```bash
mkdir -p output/dual_u_stage2/endpoint_flux

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_endpoint_flux_test \
  --output-dir output/dual_u_stage2/endpoint_flux \
  > output/dual_u_stage2/endpoint_flux/run.out \
  2> output/dual_u_stage2/endpoint_flux/run.err
```

该测试必须显式输出 `u_boundary_work` 及左右端点分项，并从初末分布、实际
最终 `J_E`、周期 x 能量边界项和端点功独立重建：

\[
R_{\rm endpoint}
=\Delta K+(\Psi^K_{x,R}-\Psi^K_{x,L})+B_u^K
-\Delta t\,\Delta x\sum_i E_iJ_{E,i}.
\]

同时必须从生产算子原样导出的分项重建：

\[
R_{\rm FV,reconstructed}
=\Delta K_{\rm production}
+(\Psi^K_{x,R}-\Psi^K_{x,L})
-U_u+B_u^K.
\]

其中 `U_u=stage5_u_energy_moment`。两条账必须分别核对，不能只比较最终
`R_FV`：

1. 独立初末分布积分的 `Delta K` 与生产 `delta_ke_bkg` 一致；
2. `U_u` 与 `dt*dx*sum(E*je_final)` 一致；
3. 均匀 x、单 rank、周期测试中的 x 空间边界项应为舍入量级；
4. 生产四分项必须重构原始 `R_FV`；
5. 完整物理余额本身必须满足阈值。

正负场必须分别激活左、右端点，并要求：

```text
endpoint_positive_balance_relative <= 1e-10
endpoint_negative_balance_relative <= 1e-10
endpoint_positive_r_fv_match_relative <= 1e-10
endpoint_negative_r_fv_match_relative <= 1e-10
endpoint_positive_production_r_fv_reconstruction_relative <= 1e-10
endpoint_negative_production_r_fv_reconstruction_relative <= 1e-10
endpoint_positive_delta_kinetic_energy_match_relative <= 1e-10
endpoint_negative_delta_kinetic_energy_match_relative <= 1e-10
endpoint_positive_u_energy_field_work_match_relative <= 1e-10
endpoint_negative_u_energy_field_work_match_relative <= 1e-10
```

其中生产 `delta_ke_bkg` 必须逐速度格点直接累加
`K*(f_final-f_initial)`，不得再以两个完整动能总量相减。`u` 功配对还必须输出
`u_energy_field_work_difference_absolute` 和 `u_energy_field_work_scale`；当两项功均因
对称性接近零时，相对误差按本次端点事件的 `Delta K`、速度端点功和 x 空间边界功
构成的物理能量尺度归一化，不能按两个近零功量自身归一化。

这里的 `r_fv_match` 用于确认独立重建与生产有限体积账本一致。端点测试不再
套用只含内部 u-face 的普通 `dual_decomposition_pass`，否则会把真实
`B_u^K` 误判成内部对偶失败。

### 5.7 单 rank 与多 rank 一致性

先运行单 rank：

```bash
mkdir -p output/dual_u_stage2/mpi_single

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_mpi_consistency_test \
  --output-dir output/dual_u_stage2/mpi_single \
  > output/dual_u_stage2/mpi_single/run.out \
  2> output/dual_u_stage2/mpi_single/run.err
```

再以与生产分区相同的方式运行多 rank。以下以 80 ranks 为例：

```bash
mkdir -p output/dual_u_stage2/mpi_multi

srun -N 10 -n 80 --ntasks-per-node=8 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_mpi_consistency_test \
  --output-dir output/dual_u_stage2/mpi_multi \
  > output/dual_u_stage2/mpi_multi/run.out \
  2> output/dual_u_stage2/mpi_multi/run.err
```

最后比较两份结果：

```bash
mkdir -p output/dual_u_stage2/mpi_consistency

./build_dual_u_stage2/background_coupling_dual_u_mpi_consistency_audit \
  output/dual_u_stage2/mpi_single/summary.result \
  output/dual_u_stage2/mpi_multi/summary.result \
  --output output/dual_u_stage2/mpi_consistency/summary.result \
  > output/dual_u_stage2/mpi_consistency/run.out \
  2> output/dual_u_stage2/mpi_consistency/run.err
```

MPI 一致性汇总器同样是串行程序，必须直接执行或仅使用一个 task。只有
`mpi_single` 中 `mpi_size=1` 且 `mpi_multi` 中 `mpi_size>1` 时结果才有效。

多 rank 数量必须满足空间网格分区要求。不要用不同网格或不同 MPI 数量生成的 midpoint checkpoint 交叉重放。

`min_f_dual < 0` 且所有数据有限时，不能单独据此判失败。失败必须由质量、动量、端点功、耦合误差、非有限值或测试规定的宏观阈值触发。

修订后的判定还必须满足：

1. 相位测试使用可整格平移的 `mode=4`，将 `pi/2` 结果平移 50 个 x cell 后逐点比较 `J_N`、`G*J_E`、残差和完整背景状态；只比较全局范数不算通过。
2. 正负场测试以零场结果为共同参考，先逐点组成响应再确定性求矩，分别检查动量、完整状态和 u-face 通量的奇对称，以及 `J_N`、`G*J_E` 的偶对称。
3. 独立非均匀网格测试必须使用非零场和非零平滑扰动，并要求 `nonuniform_operator_active_pass=1`。
4. 三档制造态必须把 `J_N-G*J_E` 拆成局部 u 对偶误差、固定空间投影底噪 `J_N-G*GJ_N` 和投影重构误差。固定 x 网格下的完整面残差允许停在投影底噪，但局部对偶误差和投影重构误差必须满足阈值。
5. 端点测试必须用正负场分别激活左右 u 端点，并独立检查 `total=left+right`、质量、动量、`Delta K+Psi_x+B_u^K-dt*dx*sum(E*J_E)` 账本，以及生产 `Delta K+Psi_x-U_u+B_u^K` 对 `R_FV` 的重构。
6. MPI 汇总不得比较已经处于消差舍入量级的绝对质量残差；应检查两次运行各自的归一化守恒误差，并对非零物理量逐字段输出差异和最差字段名。

## 7. 推荐执行顺序

按以下顺序独立提交：

1. 阶段 1 预检；
2. 零场 Maxwellian；
3. 正负微小均匀场；
4. 相位平移；
5. 非均匀柱坐标速度网格；
6. u 端点非零通量；
7. Nupar=48/96/192 三档；
8. 三档汇总；
9. 单 rank；
10. 多 rank；
11. MPI 一致性汇总。

前一项出现 NaN/Inf、质量或动量守恒失败时，不应继续用后续汇总掩盖失败。

## 8. 快速检查

检查所有正式结果是否产生：

```bash
find output/dual_u_stage2 -name summary.result -type f -print
```

检查失败项：

```bash
grep -R "^passes=0" output/dual_u_stage2 --include="summary.result"
```

检查非有限值：

```bash
grep -R -Ei "nan|inf" output/dual_u_stage2 \
  --include="*.result" --include="*.err"
```

只有全部要求目标存在、所有 `summary.result` 属于同一代码批次，并且对应验收项通过后，才能进入阶段 3。

## 9. 本轮端点诊断后的最小执行与最终验收

### 9.1 立即执行的定位测试

本轮只增加只读诊断字段，未修改物理推进。首先只需重新编译并运行：

```bash
cmake --build build_dual_u_stage2 -j 16 --target \
  background_coupling_dual_u_endpoint_flux_test

srun -N 1 -n 1 --cpu-bind=cores \
  ./build_dual_u_stage2/background_coupling_dual_u_endpoint_flux_test \
  --output-dir output/dual_u_stage2/endpoint_flux \
  > output/dual_u_stage2/endpoint_flux/run.out \
  2> output/dual_u_stage2/endpoint_flux/run.err
```

按以下顺序解释结果：

1. `production_r_fv_reconstruction_relative` 失败：生产 `R_FV` 分项记录或导出不一致；
2. `delta_kinetic_energy_match_relative` 失败：最终态快照与生产 `delta_ke_bkg` 不同源；
3. `u_energy_field_work_match_relative` 失败时，先检查
   `final_coefficient_available=1`、`u_flux_coefficient_relation_relative`、
   `production_u_energy_reconstruction_relative` 和
   `final_current_work_reconstruction_relative`。测试现在直接导出与
   `fu_final` 配对的 `cu_final`，分别用两者以 long double 重构 u 功矩和
   `je_final` 场功；只有重构链也失败时才能判为不同源。若两条重构通过且
   `u_work_roundoff_limited=1`，原来的约 `1e-19 J/m2` 差值属于速度维和空间维
   两次消差的舍入底噪，不得据此修改 dual-u 系数；
4. `spatial_boundary_relative` 非舍入量级：周期 x 能量面闭合异常；
5. 上述均通过但 `balance_relative` 失败时，检查
   `final_state_energy_gross_scale`、`balance_roundoff_bound` 和
   `balance_roundoff_limited`。最终态 `Delta K` 现在从逐速度单元的
   long-double 差分并按 rank 固定顺序求和。舍入上界不再使用总背景动能乘
   统一运算次数；测试从 `fx_final/fu_final` 逐单元重放单子步更新，并输出
   `local_update_replay_available`、`local_update_energy_defect_signed/absolute`
   和 `local_update_energy_ulp_bound`。紧上界只包含实际更新重放缺口、各最终
   质量值的局部 ULP 和已经独立测得的 u 功消差误差。若该紧预算仍不能覆盖
   余额，才判为有限体积端点更新的真实残差。
6. `r_fv_match_relative` 略超固定阈值时，必须同时检查
   `r_fv_match_difference_absolute`、`r_fv_match_roundoff_bound` 和
   `r_fv_match_roundoff_limited`。该预算仅由独立/生产 `Delta K` 路径差、
   u 功路径差、生产分项重构差和局部 ULP 组成；只有预算覆盖实际差值时才
   接受，不允许单纯扩大 `1e-10` 常数阈值。

舍入接受不是直接放宽常数阈值：只有同源重构全部通过，并且残差小于由本次
实际运算规模、绝对通量和最终态总动能计算出的舍入上界时才允许通过。不得在
确认上述分支前修改 dual-u 系数。

### 9.2 不修改生产算子时的补充审计

若 9.1 只发现测试/导出问题且没有修改生产算子，则：

1. 修正审计后重跑端点测试；
2. 等 `manufactured_coarse/base/fine` 三份文件全部写完后，单进程重跑制造态汇总器；
3. 已通过的 MPI 单/多 rank 生产结果无需重复生成，但应保留其 `passes=1` 汇总。

### 9.3 修改生产算子后的最终 Stage 2 回归

若根据 9.1 修改了任一生产通量、状态更新、边界通量、功矩或 `R_FV` 定义，则必须按第 7 节顺序完整重跑全部七类测试。最后必须完成两项串行审计：

1. 三档制造态收敛汇总，且汇总时间晚于三档生产结果；
2. 单 rank/多 rank MPI 一致性汇总。

最终检查：

```bash
grep -R "^passes=0" output/dual_u_stage2 --include="summary.result"
grep -R -Ei "nan|inf" output/dual_u_stage2 \
  --include="*.result" --include="*.err"
```

第一条必须无输出，第二条不得出现数值型 NaN/Inf。满足后才允许进入阶段 3。
